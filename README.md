# Vanit Dantani - Personal Portfolio

This is my professional portfolio website built to showcase my professional details, skills, and projects.

## 🚀 Features

- Modern and responsive design
- Showcase of professional projects and experience
- Contact information and social links

## 🛠 Tech Stack

- React
- JavaScript (ES6+)
- HTML5 & CSS3

## 💻 Getting Started

To run this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/VanitDantani/vanit-dantani-portfolio.git
   ```
2. Navigate into the directory:
   ```bash
   cd vanit-dantani-portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
